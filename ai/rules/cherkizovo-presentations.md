# Cherkizovo / MICHURIN — рекомендации по оформлению слайдов

Использовать этот файл как обязательный контекст при создании и правке презентаций для Черкизово (шаблон MICHURIN и производные).

## 1. Базовые корпоративные стандарты (Черкизово)

### Шрифт

- **Корпоративный шрифт: Verdana** — использовать во всех презентациях.
- Заголовки: Verdana Bold.
- Основной текст: Verdana Regular.
- Исключение: если конкретный утверждённый шаблон (например, табличный отчёт пилота) явно задаёт другой шрифт для таблиц — следовать шаблону, но по умолчанию приоритет у Verdana.

### Логотип

- **Запрещено** размещать логотип MICHURIN на слайде **без** логотипа Черкизово.
- Логотип Черкизово: красная эмблема + «ЧЕРКИЗОВО» + «С 1974».
- Фон логотипа в файле: **белый** (не чёрный).
- Размещение в табличных шаблонах: **правый верхний угол** слайда.

---

## 2. Дополнительные правила шаблона MICHURIN

1. **Зелёный акцентный цвет** (RGB 25, 150, 70 / `#199646`) — только как акцент, **не более 15%** площади слайда.
2. **Титульные слайды (обложки):** в мастере 7 вариантов. Варианты 6 и 7 — только для исключительных массовых внутренних презентаций. Если не нужны — удалить из файла для уменьшения размера.
3. **Логотип MICHURIN** всегда в паре с логотипом Черкизово (см. выше).

## 5. Макет и отступы (табличные слайды)

Формат слайда: **16:9** (13.333" × 7.5" / 960 × 540 pt).

| Параметр              | Значение   |
|-----------------------|------------|
| Отступ слева (таблица)| 0.583"     |
| Отступ справа         | 0.267"     |
| Отступ снизу (мин.)   | 0.267"     |
| Верх таблицы          | 1.127"     |
| Верх заголовка        | 0.361"     |
| Верх логотипа         | 0.112"     |
| Логотип: left / width | 10.255" / 2.65" |

### Правила размещения строк таблицы

- Если строка **не помещается** на слайд — переносить на **следующий** слайд.
- Если строк **мало** — **не растягивать** их по высоте; сохранять естественную высоту по содержимому.
- Минимальная высота строки данных: **0.742"**.
- Высота строки оценивается по переносу текста в колонках «Задача», «Ценность», «Статус».

### Ширины колонок (шаблон «Дефекты и разработки по Пилоту»)

| Предварительная оценка, тыс.руб.     | 1.306"  |

## 6. Структура табличного слайда «Дефекты и разработки по Пилоту»

**Заголовок:** `Дефекты и разработки по Пилоту (n/N)`

**Колонки:**

1. №пп
2. Ключ
3. Задача
4. Ценность
5. Предварительная оценка реализации, тыс.руб.
6. Статус

**Оформление таблицы:**

- Заголовок: фон `#AF182E`, текст белый, по центру.
- Строки: чередование белый / `#F8E7E8`.
- Границы ячеек: тонкие чёрные.
- Критичные значения: `#FF0000`, жирный.
- Оценка: выравнивание по правому краю.

## 7. Фильтрация данных (текущий проект)

При генерации из CSV `data/RTR-status.csv`:

- Включать строки, где есть **«Осипова»**.
- Исключать строки, где есть **«важно»** (в любом поле).

---

## 8. Чеклист перед сдачей презентации

- [ ] Шрифт Verdana (или Calibri только в таблицах по образцу)
- [ ] Цвета из палитры раздела 3
- [ ] Зелёный акцент ≤ 15% площади слайда
- [ ] Логотип Черкизово на каждом слайде; MICHURIN только вместе с Черкизово
- [ ] Логотип на белом фоне
- [ ] Отступы соответствуют разделу 5
- [ ] Строки не растянуты искусственно
- [ ] Переполнение строк перенесено на следующий слайд
