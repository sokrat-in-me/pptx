# Генератор презентаций в стиле Черкизово

Скрипт создаёт PowerPoint-презентацию по корпоративному шаблону (на основе PDF «Критика отчетности ERP по сегментам») из данных задач команды RTR-УУ.

## Быстрый старт

```bash
pip install -r requirements.txt
python generate_presentation.py
```

Результат: `output/RTR-UU-backlog.pptx`

## Данные

Задачи описаны в `data/tasks.json`. Для добавления новых строк скопируйте структуру существующей записи:

- `category` — тип задачи (Ошибка функционала, Разработка, Новое требование и т.д.)
- `is_refinement` / `is_new` — отметки «V» в колонках доработки и новой задачи
- `task_key`, `description`, `complexity` — ключ ЯТ и описание
- `analytics_hours`, `dev_hours` — трудозатраты в часах
- `value` — бизнес-обоснование (префикс «ВАЖНО!» выделяется красным)

## Структура слайда

| Категория | Доработка | Новая задача | Ключ / Описание | Трудоемкость, ч** | Value |
|-----------|-----------|--------------|-----------------|-------------------|-------|

Оформление повторяет шаблон: логотип Черкизово, бордовая шапка таблицы, сноски внизу слайда.
