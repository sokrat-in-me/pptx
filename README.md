# Генератор презентации «Дефекты и разработки по Пилоту»

Скрипт формирует PowerPoint-презентацию по шаблону из PDF на основе данных CSV.

## Результат

- `Дефекты_и_разработки_по_Пилоту.pptx` — презентация со всеми задачами пилота

## Запуск

```bash
pip install -r requirements.txt
python generate_presentation.py
```

### График запуска RTR

```bash
python generate_launch_schedule.py
```

Результат: `График_запуска_RTR.pptx` — диаграмма Ганта по данным `data/RTR-launch-schedule.csv` (2 слайда с таблицей, периоды сгруппированы по годам и месяцам).

## Структура слайдов

Каждый слайд повторяет шаблон PDF:

- заголовок `Дефекты и разработки по Пилоту (n/N)`
- логотип Черкизово справа
- таблица из 6 колонок

В презентацию попадают строки CSV, где встречается **«Осипова»** и отсутствует **«важно»**.

| Колонка шаблона | Источник в CSV |
|---|---|
| №пп | порядковый номер |
| Ключ | Ключ задач в ЯТ |
| Задача | Дефект + описание задачи |
| Ценность | value / комментарии |
| Предварительная оценка | Стоимость разработки, тыс.руб. |
| Статус | Разработка / релиз / статус ЧТЗ |
