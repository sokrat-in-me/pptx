# Генератор презентации «Критика отчетности ERP по сегментам»

Скрипт формирует PowerPoint-презентацию по шаблону из PDF на основе данных CSV.

## Результат

- `Критика_отчетности_ERP_по_сегментам.pptx` — готовая презентация (9 слайдов, 51 задача по отчетности)

## Запуск

```bash
pip install -r requirements.txt
python generate_presentation.py
```

## Структура слайдов

1. Титульный слайд с дедлайнами релизов
2. Таблицы задач по шаблону: Сегмент | Доработка отчета | Новый отчет | Описание | Трудоемкость | Предложение
3. Сводка по сегментам

## Маппинг данных CSV → шаблон

| Колонка шаблона | Источник в CSV |
|---|---|
| Сегмент | Команда / Сложность / ключевые слова в описании |
| Доработка отчета (V) | Дефект: ошибка функциональности и др. |
| Новый отчет (V) | Дефект: новое требование, разработка |
| Описание | Описание задачи |
| Трудоемкость | Оценка аналитики + оценка разработки (часы) |
| Предложение | Релиз, блокировка тиража, комментарии, ключ задачи |

В презентацию попадают задачи, связанные с отчетностью (по описанию или проектному решению).
